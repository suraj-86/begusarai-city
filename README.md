🚀 My First Web Project – Begusarai City Website

This project marks my first step into real-world web development. The Begusarai City Website is designed to present information about the city in a clean, modern, and user-friendly way. It showcases important places, culture, and highlights of Begusarai while focusing on simplicity and responsiveness.

Through this project, I explored the fundamentals of frontend development, improved my design thinking, and learned how to deploy a live website.
